# PhiShield

PhiShield é uma extensão web desenvolvida para detectar URLs potencialmente maliciosas, com foco na identificação de ataques de phishing e outras ameaças cibernéticas.  
A solução utiliza APIs de segurança amplamente reconhecidas, como Google Safe Browsing e PhishTank, para fornecer análises confiáveis em tempo real.

## Funcionalidades

- Análise de URLs suspeitas  
- Interface web simples e intuitiva  
- Classificação de risco: Seguro, Suspeito ou Malicioso  

## Tecnologias Utilizadas

- Python  
- Flask  
- HTML, CSS e JavaScript
