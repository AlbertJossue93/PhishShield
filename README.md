# PhiShield

## Português

PhiShield é uma extensão de navegador para google Chrome web voltada para a detecção de URLs potencialmente maliciosas, com foco na identificação de ataques de phishing e outras ameaças cibernéticas.

### Funcionalidades

- Análise de URLs suspeitas
- Interface web simples e intuitiva  
- Classificação de risco (seguro, suspeito, malicioso)  

### Tecnologias Utilizadas

- Python  
- Flask  
- HTML, CSS e JavaScript  

### Como Executar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/phishshield.git
2. Instale as dependências:
pip install -r requirements.txt
3. Execute a aplicação:
python run.py
4. Acesse no navegador:
http://127.0.0.1:5000
